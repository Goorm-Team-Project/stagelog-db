# stagelog-db

### .env.example 파일 사용법
- 해당 파일은 환경변수 파일입니다. 코드를 로컬로 가져온 후, 파일명에서 .example을 지우고, `.env` 파일로 사용합니다.
- 파일을 열어 현재 환경에 맞게 환경변수를 등록합니다.
- 파이썬 코드와 같은 다른 코드 파일에서 환경변수 값을 직접 타이핑하지 않고, 오직 환경변수 파일만을 이용해서 해당 데이터를 불러오는 방식으로 사용합니다.

###  kopis_to_rds
- KOPIS API를 통해 공연 데이터를 가져온 후 정재 및 RDS에 적재
- KOPIS에서 오는 본명 아티스트명 데이터를 OPENAI API를 이용해서 활동명으로 변경 후 RDS에 적용

### find_groupname 폴더
- KOPIS에서는 존재하지 않는 그룹명 데이터를 OPENAI API를 이용해서 찾은 후 RDS에 적용
- 그룹명 찾는 조건 : 아티스트명이 2명 이상인 공연 중에서 한국 아이돌
